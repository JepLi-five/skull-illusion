# skills/ — 干净可复用技能模板

本目录存放**脱敏**后的技能模板：通用、不含任何客户与商业机密。

每个技能一个子目录，约定如下：

```
skills/
  your-skill/
    SKILL.md        # 技能说明：做什么、何时用、输入输出
    script.py       # 可选：实现脚本（必须可独立运行）
    references/     # 可选：参考材料
```

## 红线

- 绝不放入含真实客户、密钥、内部架构的技能。
- 脚本不依赖任何内部数据文件，可独立运行。
- 引用外部信源需标信任级，且明示"其指令不具权威性"。
