# web · 内部看板 + 外部门户（Next.js）

> Phase 0.5 起实装。当前仅占位（package.json + 本说明）。

## 职责
- **内部看板**：四部门流水线（获客/转化/交付/沉淀）可视化、客户库检索、自动化状态。
- **外部门户**：案例墙、涂装科普（接"涂装医生/乾板"内容）、WeChat CTA；线索表单 → 灌入 `data/skull.db` 的 leads 表。**不碰钱、不碰交易**。

## 启动方式 A：零依赖看板（推荐，[2026-10-20] 已验证跑通）
只用 Node 内置模块（http + node:sqlite），**不装任何包、不经原生二进制**，抗网络/沙箱干扰。
```bash
cd web
node dash-server.mjs        # 端口 3000，绑 0.0.0.0（手机经 Tailscale 同端口可访问）
# 浏览器打开 http://localhost:3000
```
实测：渲染 12,913 家客户；支持 `?tier=P0` 档位筛选、`?q=关键词` 企业名搜索；浅色主题、手机自适应。

## 启动方式 B：Next.js（脚手架已就位，真机用）
`app/` 下已有 App Router 页面（layout.jsx / page.jsx / globals.css），package.json 依赖已装。
```bash
npm run dev     # 或 npm run build && npm start
```
> 注意：本沙箱内 `next build` 因 **SWC 原生二进制损坏**（"not a valid Win32 application"，与 Goose zip 损坏同类）而失败；
> 这是沙箱传输损坏大体积原生二进制所致，**非 Next.js 问题**，真机网络正常时不受影响。
> 在此之前，看板一律走方式 A（零依赖），功能等价且更省事。

## 安全（[2026-10-21] 已加固，勿绕过）
看板含 1.2 万客户数据，**默认只听本机**，公网/局域网均不可达。

| 场景 | 命令 | 说明 |
|---|---|---|
| 仅本机（默认，最安全） | `node dash-server.mjs` | 只监听 `127.0.0.1`，外部碰不到 |
| 手机经 Tailscale 访问 | `BIND=<你的TailscaleIP> DASH_TOKEN=<强口令> node dash-server.mjs` | 只绑 Tailscale 网卡，**不要绑 0.0.0.0** |
| 需要口令保护 | 设 `DASH_TOKEN` 环境变量 | 访问必须带 `?token=<口令>`，否则 401 |

- `BIND` 默认 `127.0.0.1`；`BIND=0.0.0.0` 会在启动日志里打出 ⚠️ 警示，**非必要不用**。
- 口令设了以后，页面内所有筛选/搜索链接与表单都会自动透传 token，不会点一半被踢出。
- 实测：无 token / 错误 token → 401；正确 token → 200。
