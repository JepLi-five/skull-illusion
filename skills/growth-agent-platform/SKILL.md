# growth-agent-platform · 成长型 Agent 平台（多租户量产模板）

> version: 1.2.0

## 做什么
把"为单个客户做的 Agent"固化成**可量产接入新客户**的成长型平台模板：配置化 + 插件热插拔 + 多租户聚合看板 + Agent 联网协作 + 明账账本 + 防跳单闸门。内置 M1–M5 全链路与一键接入脚本，**自包含、开箱即跑**（契约层与演示资产均已内置，无需外部客户包）。

## 何时用
- 想把自己的"单客户 Agent"升级成"能服务 N 个客户的平台"；
- 需要一套零依赖、可分发的多租户 Agent 脚手架参考；
- 想把"接新客户"从改代码变成"写一条配置 + 一条命令"。

## 怎么用
```bash
cd assets/platform_m2

# 0) 先把名单导进来（任意 Excel/CSV，列名乱也能认；可反复追加、可关键词检索）
python 导入线索.py --input "D:/名单.xlsx" --add --keyword "铸造,示例市"

# 1) 演示：开箱跑通 M2–M5（含真实 A2A/HTTP + 明账/防跳单 + 聚合看板）
python run_m4_transport.py

# 2) 接新客户（一键，红线自动校验 ≤10 行脱敏样例）
python onboard_client.py --id profile_003 --company "某某新材料" --industry 工业漆 \
    --region 示例市 --staging /path/to/脱敏样例.csv --share 0.08 --cpl 30

# 3) 再跑一次，新客户自动并入多租户看板
python run_m4_transport.py

# 4) 出该客户自己的看板（只含该客户数据，可当面交付给客户）
python 单租户看板.py --tenant profile_003 --out 看板.html
```
交付话术要点与真实客户实测记录见 `assets/platform_m2/接入手册.md` 第四、五节。
接入细节见 `assets/platform_m2/接入手册.md`（含「先导名单，再接客户」的推荐顺序）。

## 能力（里程碑）
- **M1 配置化**：新增客户 = 加一条 `ClientProfile`，不碰主程序。
- **M2 插件热插拔**：三腿（线索检索 / 企微自动回复 / 短信触达）拆为 `plugins/<leg>/` 独立目录，自动发现加载。
- **M3 多租户聚合**：事件带 `tenant_id` 落盘，聚合成跨租户看板。
- **M4 Agent 联网**：获客/转化/交付/沉淀四 Agent 经**真实 A2A(HTTP)** 协作（对齐 A2A 信封，零依赖）。
- **M5 明账 + 防跳单**：双时态流水账 + 留痕/排他期/跳单嫌疑自动告警。
- **量产接入**：`onboard_client.py` + `tenants/registry.json`。
- **名单导入（v1.2.0）**：`导入线索.py` 把任意格式名单（Excel / CSV / TXT）转成平台标准 11 列——**列名自动映射**（公司名称 / 厂名 / 老板 / 手机号 / 地址 / 注册资本…都认）、**认不出的列收进备注不丢**、`--add` 追加去重、`--keyword` 关键词检索（覆盖企业名称 / 地区 / 行业 / 需求信号 / 评分档位 / 备注）。零依赖读 `.xlsx`（**不需要 openpyxl**），自动跳过文档标题行，兼容 UTF-8 / GBK。
- **客户交付**：`单租户看板.py --tenant <id>` 产出只含该客户自身数据的看板（三腿 KPI + **本期线索明细** + 线索档位 / **县级区域分布** + 明账明细 + 防跳单提醒 + 数据主权声明），严格 `tenant_id` 双保险过滤，跨租户泄漏 0 处，可当面交付客户本人。
- **v1.1.2 补丁**：客户看板补齐两处"客户视角硬伤"——① 区域从村级地名聚合到 `市/县/区/旗`（原本每个村各计 1 条，图上全是碎条，看不出盘子分布）；② 新增**本期线索明细表**（企业名称 / 地区 / 档位 / 需求信号 / 公开联系方式），客户最关心的"到底捞上来哪些厂"不再缺位。

## 红线（公开承诺）
- 客户数据主权归客户；核心资产（主表 / 评分引擎 / 采集管线）**永不出门**，包内仅保留 ≤10 行脱敏占位样例。
- 明账透明 + 防跳单：成交须经 Agent 首次触达留痕，排他期（默认 24 个月）内归因非 Agent 渠道的成交自动标跳单嫌疑并入账。
- 全部示例数据均为编造占位；企微 / 短信的真实凭据由客户自行填入环境变量，不写入受控包。

## 依赖
仅 Python 3 标准库，零外部依赖。
