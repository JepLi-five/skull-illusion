# 一人公司四部门管理法

> 适用于「只有一个人」的销售 / 服务公司。核心思想：把公司当成一个**系统**来运营，而不是靠脑子记。

## 为什么需要它

- 一个人就是一支队伍，所以任何"靠记性"的环节都是致命的——回款忘了催、复购忘了跟，直接丢钱。
- 没有同事指出你的盲区，所以系统必须持续做"盲目区诊断"，不能只执行。
- 你的经验如果只在脑子里，公司就没有资产——隐秘区必须持续录入，让系统能继承。

## 四部门结构

| 部门 | 职责 | 系统覆盖目标 |
|---|---|---|
| 获客部 | 线索采集、核录、补全、分档 | 自动化抓取 + 评分分层 |
| 转化部 | 报价、谈价、跟进、成单 | 话术模板 + 流程化 |
| 交付部 | 订单、账期、回款、复购 | 台账 + 自动提醒 |
| 沉淀部 | 知识库、盲区雷达、回流 | 经验结构化入库 |

## 三条铁律

1. **任何靠记性的环节都落到表、落到自动化**——人脑不可靠，机器才可靠。
2. **系统必须持续做"盲目区诊断"**——不能只做执行，要有人（或 AI）指出你看不到的盲区。
3. **经验只在脑子里 = 公司没有资产**——隐秘区必须持续录入，让系统能继承。

## 怎么用

把每个部门拆成"可继承、可自动执行、可随身带"的流程。配套资产见仓库 `skills/` 与 `tools/`。
