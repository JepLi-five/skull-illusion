# redline-scan · 红线 / 敏感信息扫描器

## 做什么
扫描文件或目录，识别潜在的敏感信息：手机号、身份证、邮箱、API Key、密码、金额等，输出**命中位置 + 类型 + 脱敏摘要**，绝不输出命中内容本身。

## 何时用
- 任何内容准备公开 / 外发前，先扫一遍。
- 检查代码仓库、文档是否误含密钥、客户数据。
- 把仓库推到公开平台前的最后一道闸。

## 怎么用
```
python scan.py <path> [--json]
```
`<path>` 可为文件或目录（自动递归 `.md/.txt/.py/.json/.csv/.yaml`）。

## 输出
- 人类可读：每行 `文件:L行号 类型 脱敏摘要`
- `--json`：结构化输出，便于接入自动化。

## 红线
脚本本身**不含任何真实敏感数据**；匹配模式为通用正则，示例均为占位。
