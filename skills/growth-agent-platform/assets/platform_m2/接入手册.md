# 成长型 Agent 平台 · 新客户接入手册（M5 收口）

> 目标：把「一人公司接新客户」从改代码变成**写一条配置 + 一条命令**。
> 平台已支持 M1 配置化 / M2 插件热插拔 / M3 多租户聚合 / M4 真实 A2A / M5 明账+防跳单。

## 〇、先把名单导进来（推荐先做 · v1.2.0）

真实场景里，客户手上早就有名单了（Excel / 通讯录导出 / 别人给的黄页表），列名叫法五花八门。
先把它转成平台标准格式，后面的检索、看板、接入才有数据可跑：

```bash
python 导入线索.py --input "D:/客户名单.xlsx" --add
```

- **列名自动映射**：公司名称 / 厂名 / 单位名称 / 老板 / 手机号 / 地址 / 注册资本 / 主营产品… 都认；
- **认不出的列不丢**：统一收进「备注」（形如 `旧列名:值`），信息零损耗；
- **`--add` 追加去重**：按企业名称跳过重复，多批名单可以反复往里加；
- **`--keyword` 检索**：`--keyword "铸造,示例市"`，多个关键词是「或」，检索覆盖企业名称 / 地区 / 行业 / 需求信号 / 评分档位 / 备注；
- **零依赖读 Excel**：不需要 `openpyxl`，自动跳过文档标题行，兼容 UTF-8 / GBK。

产物是 `我的线索库.csv`（默认名，可 `--out` 改）——**这是客户自有数据，行数不受限**。
红线②约束的是「乙方主表不得进平台包」，与客户自己的名单库无关；只有在用 `onboard_client.py`
做**平台演示**时才需要另取 ≤10 行脱敏样例。

## 一、前置（一次性）
- 客户交付包（如 U 盘）已就位（只读引用，红线②）；`template_assets/` 内置通用占位演示资产，开箱即可跑。
- 平台目录 `platform_m2/` 已就绪（零依赖，Python 3 标准库即可跑）。

## 二、接入新客户（一条命令）
```bash
cd platform_m2
python onboard_client.py \
  --id profile_003 \
  --company "某某新材料" \
  --industry 工业漆 \
  --region 示例市/示例市B \
  --staging /path/to/脱敏样例.csv \   # 必须用 ≤10 行脱敏样例，严禁主表
  --share 0.08 \                      # 分成比例 8%
  --cpl 30                            # 单线索成本（元）
```

`onboard_client.py` 自动完成：
1. **红线校验** —— staging 行数必须 ≤10，否则拦截（主表/评分引擎/采集管线永不出门）。
2. **自包含拷贝** —— 样例拷入 `tenants/<id>/staging_脱敏样例.csv`，平台不再依赖客户原始路径。
3. **写入注册表** —— `tenants/registry.json` 追加一条租户配置（配置化，主程序零改动）。
4. **初始化账本** —— `ledger/<id>.csv` 建好，M5 明账/防跳单即生效。

## 三、并入多租户看板（一条命令）
```bash
python run_m4_transport.py
```
该命令会：M2 跑所有租户插件 → M4 四 Agent 真实 A2A 协作 → M5 写账本+防跳单 → M3 重建
`多租户看板_M3_<日期>.html`（含每个客户的明账/防跳单区块）。

## 四、出客户自己的看板（交付给客户本人）

```bash
python 单租户看板.py --tenant profile_003 --out /path/to/看板.html
```

产出**只含该客户自身数据**的 HTML（零依赖、可离线打开、无 CDN）：

- 三腿运行 KPI（线索检索 / 企微自动回复 / 短信触达）
- 线索库档位与**地区分布（按 市/县/区/旗 聚合）**
- **本期线索明细表**：企业名称 / 地区 / 评分档位 / 需求信号 / 公开联系方式 — 客户最关心的「到底捞上来哪些厂」
- **M5 明账账本**：线索数 / 成交数 / 预估分成 / 成本 / 净收益 + 逐条双时态明细（业务日 + 落账时）
- **防跳单提醒**：排他期内的归因告警
- **数据主权与边界声明**：明写乙方主表 / 评分引擎 / 采集管线不进入客户系统

**隔离机制**：事件与账本按 `tenant_id` 双重过滤（文件名 `events_<id>.csv` / `ledger_<id>.csv` + 行内再校验 `row[0] == tid`），非本租户行直接丢弃——可当面交付客户，不必担心串户。

**交付话术要点（谈判用）**

- **明账先亮**：先给客户看「净收益是怎么算出来的」，这是建立信任成本最低的一条路。
- **防跳单摆上台面**：排他期与归因规则**事前讲清并写进看板**，比事后扯皮强得多。
- **数据主权当卖点**：明确「你的数据只出现在你自己的看板里」，对老板级客户尤其有效。

## 五、实测记录（脱敏）

一家真实意向客户跑通全流程的结果：

| 环节 | 结果 |
|---|---|
| 红线闸（≤10 行脱敏样例） | 15 行违规 → 拦截；10 行 → 放行 |
| `onboard_client.py` 四步接入 | 全过（红线校验 / 自包含拷贝 / registry / 账本初始化） |
| 全链路并入 | 线索 3 / 成交 2 / 跳单告警 1，账本双时态 8 行逐条核对 |
| 客户版看板 | 7.3 KB，跨租户泄漏核验 **0 处**（其他租户 / 品牌词 / 行业词全部 0 命中） |

## 六、红线纪律（必守）
- ② 客户数据主权归客户；乙方核心资产（主表/评分引擎/采集管线）**永不出门**，平台内至多保留 ≤10 家脱敏样例。
- ③ 明账透明 + 防跳单：排他期 24 个月内、归因非 Agent 渠道的成交自动标跳单嫌疑并写入账本。
- 商务结构：搭建费 3k–5k + 月费 1.5k–2.5k + 分成 5%–10%（见各租户 commercial 配置）。
