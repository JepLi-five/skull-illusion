# 球球·心象（Qiuball Imagery）

诗词歌赋 → 配套图片 / 动图 / 视频（含朗诵）生成器。

## 三种产出形态（消费灵活，任选）
- 图片：单张高清意境图（文生图），约 5-10 积分，最省。
- 动图：单镜 5 秒动态（文生视频），约 50-100 积分。
- 视频：多镜头叙事成片（含免费朗诵），甲/乙可选，约 50-300 积分。

## 怎么用
打开 poem_video_web.html（单文件零依赖）：选模板或任意填写诗词赋 -> 选产出形态与模式 -> 出 prompt + 预算 + 朗诵试听 -> 导出任务单。画面由 AI 搭档球球接手生成。

## 文件
- poem_video_web.html 网页生成器
- poem_video_generator.py 生成器内核脚本（含免费 TTS 朗诵）
- docs/ 转译文档 + 底本核验记录
- videos/ 带印记成品样例

## 印记
所有成品右下角带「球球·心象 生成」。
