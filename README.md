# 骷髅幻戏 · skull-illusion

> 一套「可装载的 AI 协作操作系统」种子——把"怎么用 AI 管一家一人公司"的方法论、技能模板、工具脚本开放出来。任何人 clone 后，都能在自己的工作台里显形一个会管获客 / 转化 / 交付 / 沉淀的数字伙伴。

## 它是什么
骷髅幻戏不是某个具体软件，是一颗**种子（模式）**：一套能反复长出的协作契约与技能骨架。它把单人公司最痛的三件事——获客、转化、交付——用可继承、可随身带、可自动执行的系统接管起来。

## 能力展示
- 一人销售公司的「四部门管理法」（获客 / 转化 / 交付 / 沉淀）
- 通用技能模板（全部脱敏，不含任何客户与商业机密）
- **成长型 Agent 平台**：把「单客户 Agent」升级为「多租户量产接入」模板（配置化 / 插件热插拔 / 多租户看板 / Agent 联网协作 / 明账+防跳单，M1–M5 全链路，零依赖自包含；v1.1 起支持 `--tenant` 单租户交付看板，含交付话术与实测记录）→ [skills/growth-agent-platform](skills/growth-agent-platform/SKILL.md)
- 文本 / 报表处理类通用工具脚本
- 心智工坊：把经验结构化沉淀的模板
